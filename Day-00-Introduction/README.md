## The Tracks — Part 1

**Level 1: the foundation everything else stands on**

**1. JS/TS Foundations + Web Basics**
Core JavaScript, ES6+, async, TypeScript, Git — plus HTML/CSS/DOM refreshers.
*Project: Task Manager App.*

**2. Full-Stack Web Application**
React front-end, Express/Node back-end, auth, databases, deployment.
*Capstone: a live, deployed course platform.*

**3. Mobile Development (React Native)**
Same backend, new screen. Navigation, forms, local storage, auth, and a packaged Android app.

**4. Desktop Applications (Electron)**
Turn the web skillset into an installable desktop app with file system access and a local database.

---

## The Tracks — Part 2

**Level 2: specialize into where JavaScript is headed**

**5. Chrome Extension**
Manifest, content & background scripts, extension storage.
*Project: an AI-powered article summarizer.*

**6. Automation**
Node.js scripts, scheduled cron jobs, email automation, Google Apps Script.
*Project: an automated registration system.*

**7. AI Application**
LLM APIs, prompt engineering, structured outputs, embeddings, RAG, agents, MCP servers.
*Project: an AI assistant that answers student questions.*

> Every track ends in its own shippable project — and all seven eventually merge into one final, integrated system.

## How We'll Run This

- **Two sessions a week** — 3 hours each, one steady rhythm for six months.
- **Concept, then build** — every module pairs an explanation episode with a step-by-step project episode.
- **Built for beginners → job-ready** — start with zero assumptions in Module 1; by the capstone you've shipped a deployed product.

### What You Need to Start

- A computer that runs VS Code
- Curiosity, not credentials
- A GitHub account (we'll set it up)
